# ASW - Architecture Solution Writer

架构解决方案编写助手 —— 一个 Trae Skill，用于生成立体彩架构解决方案文档。

## 简介

ASW（Architecture Solution Writer）是一个智能文档生成助手，通过交互式问答收集项目信息，分析用户提供的材料，自动生成符合 **"TOC-AAM-T001 中国体育彩票架构解决方案模板"** 格式的完整架构解决方案文档（.docx）。

## 功能特性

- **交互式信息收集**：分6个阶段向用户提问，系统收集项目信息
- **智能章节判断**：根据收集的信息自动判断各章节的适用性
- **标准化文档生成**：严格遵循体彩架构解决方案模板格式
- **自动化完整性检查**：生成后自动验证文档完整性

## 工作流程

```
1. 材料收集与读取 → 2. 分阶段信息问答 → 3. 章节适用性判断 → 4. 逐章内容生成 → 5. 文档输出与完整性检查
```

## 文档模板章节

| 章节 | 内容 |
|------|------|
| 第1章 | 系统概述（建设目标、范围、术语、参考文档） |
| 第2章 | 业务需求（功能性需求、非功能性需求） |
| 第3章 | 假设和约束 |
| 第4章 | 现状分析（总体介绍、差距分析） |
| 第5章 | 应用架构（总体设计、关联系统、核心场景、接口等） |
| 第6章 | 技术架构 |
| 第7章 | 数据架构（结构化/非结构化） |
| 第8章 | 迁移方案 |
| 第9章 | 安全架构（定级、威胁分析、网络安全等） |
| 第10章 | 基础架构（环境、网络、云平台、工具备份） |
| 第11章 | 成本预估 |
| 第12章 | 运维架构（可用性、可维护性） |
| 第13章 | 附录（容灾等级定义、RTO/RPO指标矩阵等） |

## 使用方式

在 Trae 中加载此 Skill 后，执行：

```
/arch-solution [项目名称]
```

Skill 将引导您完成交互式问答，最终生成完整的架构解决方案文档。

## 适用场景

- 体彩技术中心架构部的架构解决方案编写
- 需要生成符合 TOC-AAM-T001 模板的架构设计文档
- 应用类需求和项目类需求的架构方案编写
